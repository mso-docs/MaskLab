# Baseline protocol

No model baseline has been run. The frozen neutral-role/absent-belief condition is the behavioral control for each model/question/repetition, not a moving best-performing persona. Retain exact model/endpoint, dataset/split, prompt, sampling, scorer and usage records. Never compare a new condition against a differently versioned question set without explicitly labeling the change.

The synthetic fixture suite checks tooling arithmetic; passing it is not evidence about any model. Before the real study, verify provider access in a separately authorized bounded call and score a known deterministic fixture through the pipeline. Preserve negative outcomes and original raw final responses.
