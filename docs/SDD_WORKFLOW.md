# Native ACP SDD workflow

Owner: native; template version: 1.0.0. Authoritative feature: specs/001-initial-feature. Do not create a second competing Spec Kit feature tree. Integration changes require review.

1. **Intake**: capture original objective and constraints in project-brief.md.
2. **Specify**: draft stable REQ identifiers and measurable acceptance criteria.
3. **Review**: resolve open questions and record operator specification approval.
4. **Plan**: define architecture, data contracts, testing and implementation approach.
5. **Tasks**: derive small dependency-ordered TASKs linked to requirements and tests.
6. **Implement**: execute only approved dependency-ready tasks in bounded workers.
7. **Verify**: independently evaluate deliverables against acceptance criteria with actual evidence.
8. **Handoff**: record completed work, evidence, decisions and remaining tasks.

Bootstrap stops at SPEC_PENDING. No stage is automatically approved and no implementation starts. READY requires later explicit review and real registered evaluation profiles.
