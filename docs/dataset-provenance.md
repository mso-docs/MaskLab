# Dataset provenance

`examples/datasets/synthetic-v1.json` contains 24 original synthetic exact-decimal arithmetic questions generated for pipeline/paired-study fixtures. Each answer is cross-checked with Python Decimal by tests; false alternatives are constructed to be unequal. These are not a representative scientific benchmark and have not undergone independent human dataset review. Category distributions and development/evaluation IDs are fixed in the file.

No external dataset has been downloaded. Preserve original question text, options, answer keys, split IDs and hashes per version. External datasets require source/version/license/consent records and independent correctness checks before integration. Public demo uses synthetic/public material only. Protect owner research data from exports or publication unless explicitly selected and authorized.
