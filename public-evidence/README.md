# Public demo evidence

`matrix-redacted.zip` is an explicitly redacted public derivative of the saved live-provider matrix. It omits the operator-selected day's timestamps before 5 p.m. America/New_York, including provider Unix timestamps; timestamps at/after the cutoff and on other days are retained. It uses neutral ZIP metadata dates. Scientific results, including incorrect outcomes, are preserved. Its manifest provides new file hashes and the original private archive hash. Private originals remain outside Git.

This derivative is for inspection and sharing; it is not accepted by the standard MaskLab archive importer. Public-demo downloads use the same redaction. Owner downloads retain original evidence. No credentials or spending-ledger database are included. Prepared for review only; not published or pushed.

`replication-v2-redacted.zip` is the completed second broad study, separate from simulation. Its evening timestamps and data payloads are retained; its manifest identifies it as a public derivative.
