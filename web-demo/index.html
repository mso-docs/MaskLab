03 / TRY THE REAL APP

Your own local research workspace.

Download and extract the test build. It includes the compiled app, a hash-locked dependency list and saved real evidence. No Node, GPU, Docker or API key required. You need Python 3.14 and internet for the first dependency installation.

Linux / macOS

Open a terminal in the extracted masklab-test-build folder.

python3.14 -m venv .venv
.venv/bin/python -m pip install --require-hashes -r requirements.lock
.venv/bin/python -m pip install --no-deps masklab-0.1.0.dev0-py3-none-any.whl
.venv/bin/python run.py

Windows PowerShell

Install Python 3.14, then open the extracted folder.

py -3.14 -m venv .venv
.\.venv\Scripts\python.exe -m pip install --require-hashes -r requirements.lock
.\.venv\Scripts\python.exe -m pip install --no-deps masklab-0.1.0.dev0-py3-none-any.whl
.\.venv\Scripts\python.exe run.py
Open http://127.0.0.1:8000

Choose Studies → Portable evidence → saved-public-replication to inspect the real saved study. Create a new study and use synthetic tooling fixtures to try simulated execution. New runs in this build are simulated; no paid provider is configured.

Linux x86-64 is the verified platform. Windows/macOS instructions are provided but have not been verified. If port 8000 is busy, use run.py --port 8080. Stop with Ctrl+C; restart to reopen the saved workspace.
