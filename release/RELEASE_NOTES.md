# MaskLab 0.1.0-rc1 — judge test build

MaskLab measures how model answers change under independent persona and stated-belief conditions, with immutable protocols, deterministic scoring, exact-response inspection and portable evidence.

This candidate includes the full local app and a completed 4,050-response NVIDIA Nemotron study served through Nebius Token Factory. The study retains 2,427 correct, 1,473 incorrect and 150 invalid outcomes. Its all-finalized correctness is 59.93%; valid-only accuracy is 62.23%. These convenience results are not a representative benchmark or evidence of an internal causal mechanism.

Download `masklab-test-build.zip`, extract it and follow README.txt. Python 3.14 and internet for first dependency installation are required. Linux x86-64 is verified; Windows/macOS instructions are unverified. No Node, GPU, Docker or API key is needed. Saved real evidence opens in inspection-only mode; new experiments use clearly labeled simulation, without paid provider access.

Verify the ZIP against SHA256SUMS. BUILD.json records exact evidence provenance and the frozen protocol hash. The saved archive has an import-compatible derivative wrapper around unchanged approved public payloads; the original public derivative is retained separately. Software is MIT; GSM8K MIT and adapted CMU S10 CC BY-SA 3.0 notices remain distinct.

The captioned walkthrough shows the actual app and remains under three minutes. It has no spoken audio. Source package version is 0.1.0.dev0; 0.1.0-rc1 identifies this release bundle. No public hosted live inference service is included.
